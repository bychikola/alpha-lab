# Дашборд Alpha Lab

Статический отчёт. **Открывается двойным кликом по `index.html`** — ни сервера, ни сборки, ни npm.

## Почему `report.js`, а не `report.json`

Браузеры блокируют `fetch()` к локальным файлам при открытии через `file://` (CORS).
Поэтому движок пишет **два файла из одного объекта**:

| Файл | Назначение |
|---|---|
| `report.json` | машиночитаемый, для программ и тестов |
| `report.js` | тот же payload как `window.ALPHA_REPORT = {...};`, подключается через `<script src>` |

Оба генерируются из одной строки сериализации, поэтому разойтись не могут.

`report.js` в репозиторий не коммитится — это генерируемый артефакт (≈3.8 МБ на прогон).

## Как заполнить

Один прогон движка пишет отчёт сразу в папку дашборда:

```bash
uv run alpha-lab validate \
  --config configs/experiments/mr_base.yaml \
  --symbol BTCUSDT \
  --out dashboard
```

Обновите страницу — появятся вердикт, кривая доходности, просадка, цена с позицией и разбивка издержек.

## Что показывает

- **Панель вердикта** — `ЖИВА` / `МЕРТВА`, и каждый порог рядом со своим пределом: DSR против 0.95, p-value против 0.05, PBO против 0.5, сделок против 100. Чтобы было видно **почему**, а не только **что**.
- **Предупреждения** (янтарная панель) — гейты, которые в этом прогоне **не проверялись**. Например, PBO требует матрицы доходностей нескольких конфигураций; для одиночного прогона он не вычисляется, и дашборд обязан сказать это прямо, а не показывать пустое место. Предупреждения не влияют на `alive`.
- **Издержки** — комиссии, проскальзывание, funding. Если ряд ставок funding недоступен, строка помечается как отсутствие данных, а не как ноль: иначе заниженные издержки выглядели бы как факт.
- **Ёмкость** — предупреждение, когда заявки превышают заданную долю объёма бара. Это диагностика ликвидности: такой прогон оптимистичен.

## Несовместимая версия схемы

Дашборд проверяет мажорную версию `schema_version` и при несовпадении показывает сообщение вместо пустых графиков. Формат отчёта меняется — тихая пустота хуже явной ошибки.

## Проверка failure-режимов

| Что подменить в `report.js` | Что должно появиться |
|---|---|
| `window.ALPHA_REPORT = null;` | «Отчёт не найден» + команда для генерации |
| `"schema_version": "2.0"` | «Несовместимая версия схемы», **не** пустые графики |

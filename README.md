# Alpha Lab

Исследовательский полигон для проверки торговых гипотез на криптовалютных
данных Binance USDT-M. Ценность — не в генерации идей, а в **честной
отбраковке**: отличить закономерность от совпадения.

Построен так, что большинство гипотез убивается. Это нормальный режим работы.

---

## Зачем это

Розничная «альфа» в большинстве случаев — подгонка под историю. Стратегия
красиво выглядит на прошлых данных ровно потому, что из 500 вариантов
оставили лучший. Полигон существует, чтобы это ловить.

Три механизма, каждый против своего способа обмануть себя:

| Механизм | Против чего |
|---|---|
| **Purged K-Fold с embargo** | утечки через перекрытие окон |
| **Deflated Sharpe Ratio** | множественных сравнений — штраф за число попыток |
| **PBO (CSCV)** | подгонки выбора параметров под конкретный отрезок |
| **Permutation-тест** | «а может, оно само так вышло» |
| **Проверка причинности** | подглядывания в будущее |

## Главный результат

**144 конфигурации mean-reversion — ноль выживших.** Максимальный DSR 0.107
при пороге 0.95. 736 сделок на BTCUSDT, **73.5% капитала ушло в комиссии**,
доходность −80.5%.

Дополнительно: **475 конфигураций** перебора — лучший Sharpe на обучающем
периоде **+0.01**. Пространство параметров пусто.

Затем **фильтры режима** — то, что обычно предлагают как «улучшение»: вход
только при слабом тренде (ADX), порог по эмпирическому квантилю вместо k·σ,
вход только при сжатой волатильности. **92 конфигурации, ноль выживших.**
Направление угадано верно — MR тем лучше, чем слабее тренд, — но величины не
хватает. Лучший результат (ETHUSDT, +68% за 4 года, p = 0.014) при честном
счёте попыток даёт **DSR 0.042**: среди 711 конфигураций около 35 обязаны
показать p < 0.05 случайно. Это ровно тот случай, ради которого построен
полигон.

Модель при этом корректна: на синтетическом OU-процессе при θ=0.02 она
**жива** (Sharpe 1.96, DSR 0.9985), при θ=0.002 мертва. **Модель не сломана —
рынок не даёт нужного паттерна в масштабе, перекрывающем оборот.**

### Структурная премия

Дельта-нейтральный сбор funding (спот лонг + перп шорт) на BTC 2022–2025:
**+33.3%** при просадке −0.4%, издержки 0.023%. Но:

- **не обобщается**: положителен в 18 из 28 символо-лет, у 3 символов из 7;
- **тайминг вредит**: правило входа по скользящей ставке дало +9.16% против
  +33.33% у простого удержания — издержки выросли в 58 раз;
- **портфельно с таймингом**: −3.47% CAGR на 20 символах.

Премия реальна, но это свойство конкретного актива, а не закон рынка.

## Установка

```bash
uv sync          # Python 3.14 через uv
uv run pytest -q # проверить
```

Данные кладутся в `D:\alpha-lab\data` (не на `C:`).

```bash
uv run alpha-lab ingest --config configs/universe.yaml
uv run alpha-lab validate --config configs/experiments/mr_base.yaml --symbol BTCUSDT
uv run alpha-lab sweep --grid configs/grids/funding.yaml --out results/
uv run alpha-lab report --store results/ --out dashboard
```

## Ограничения

- **Статистика не ловит look-ahead.** Доказано: две гипотезы — «сигнал по
  информации до `t`» и «сигнал из самой доходности» — дают одинаковое
  распределение. Работает только проверка причинности.
- **Гейты применимы не всегда.** Для дельта-нейтральных книг `min_trades` и
  permutation-тест неприменимы; вердикт говорит «НЕ ВЫНЕСЕН», а не «МЕРТВА».
- **Слепые зоны.** Ликвидация ноги, риск биржи, депег стейбла, базис на входе
  и выходе — в числах их нет, они едут в предупреждения.
- **Pine нельзя исполнить в браузере.** Полигон проверяет синтаксис и рисует
  выход Python-модели, а не запускает Pine.

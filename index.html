Индикатор для TradingView с полноценной статистической моделью возврата к среднему: z-скор цены, динамические полосы μ ± kσ, оценка скорости возврата θ и полужизни по модели Орнштейна–Уленбека, фильтры режима волатильности, ADX и RSI, а также чёткая разметка стопа и тейка по каждому сигналу: прямые линии с ценами — зелёная TP и красная SL — с фиксированным соотношением риск:доход 1:3 (SL = 2×ATR, TP = 6×ATR). 01 · Архитектура

Из чего состоит модель

Шесть связанных блоков: каждый решает свою статистическую задачу. Вход в позицию происходит только при одновременном выполнении всех условий.

🎯

Z-score цены

Статистическое расстояние цены от среднего в единицах волатильности: z = (P − μ)/σ. При |z| ≥ 2 цена попадает в зону статистического экстремума — ожидаем возврат.

📏

Динамические полосы μ ± kσ

Адаптивный канал реверсии (обобщённые полосы Боллинджера). Среднее μ выбирается из 5 типов: SMA, EMA, WMA, VWMA, HMA — под разные классы активов.

⏳

Полужизнь (OU-процесс)

Регрессия ΔS = a + b·S оценивает скорость возврата θ = −b, а полужизнь T½ = ln2/θ показывает, за сколько баров цена «забывает» отклонение. Входы — только при значимой реверсии.

🌡️

Режим волатильности

Z-скор самого ATR в скользящем окне 100 баров. Входим только при повышенной, но не панической волатильности: в штиле нет движения, в панике σ нестабильна.

🧭

Трендовый фильтр ADX

Если ADX выше порога (по умолчанию 25) — рынок в тренде и возврат к среднему статистически невыгоден. Сигналы блокируются до восстановления боковика.

🛡️

Риск-менеджмент ATR

Индикатор чётко рисует по каждому сигналу линии SL и TP с ценовыми метками — дефолт SL = 2×ATR, TP = 6×ATR, что даёт риск:доход 1:3. В стратегии-версии объём позиции считается от процента риска: qty = E·r / (SL·pv).

🪙

Корреляция с биткоином

Скользящая корреляция Пирсона ρ с BTC за 100 баров. При |ρ| ≥ порога (0.6) монета «ходит за битком» — включается приоритет направления BTC: бычий BTC (цена выше EMA50) → только LONG, медвежий → только SHORT. Низкая корреляция — монета торгуется независимо, оба направления разрешены.

🌋

Волатильность монеты

Двухуровневый контроль: z-скор собственного ATR (режим «повышенная, но не паническая») плюс нормировка к BTC — отношение ATR монеты к ATR биткоина. Если альт в 3+ раза волатильнее битка (мемкоины, низкая ликвидность) — сигналы шумные и блокируются.

🔊

Объём и POC профиля

Дополнительные сигналы для частоты: когда цена приходит к границе MR (мягкий порог |z| ≥ 1.5), ведётся проверка объёма — всплеск volume > SMA20 × 1.5 подтверждает разворот. Отдельный триггер — касание глобального POC объёмного профиля: уровня максимального проторгованного объёма, который работает как сильная поддержка/сопротивление.

02 · Формулы

Математический аппарат

Z-score и канал реверсии

блок ①
// оценка среднего и дисперсии
μ = EMA(P, L)   σ = stdev(P, L)
z = (P − μ) / σ
Верх = μ + k·σ    Низ = μ − k·σ

По нормальному закону ~95% наблюдений лежат внутри ±2σ. Выход за канал — статистическая аномалия: открываем позицию против экстремума с целью на среднее μ.

Орнштейн–Уленбек и полужизнь

блок ②
// стохастический дрейф к среднему
dSₜ = θ(μ − Sₜ)dt + σ·dWₜ
T½ = ln 2 / θ
// МНК-оценка: ΔSₜ = a + b·Sₜ₋₁, θ̂ = −b
b̂ = (n·Σ(S·ΔS) − ΣS·ΣΔS) / (n·ΣS² − (ΣS)²)

Если θ близко к нулю (полужизнь огромная) — реверсии нет, модель «молчит». Фильтр отсекает активы и режимы, где стратегия математически не работает.

Режим волатильности

блок ③
// нормировка ATR в окне W
atrZ = (ATR − SMAW(ATR)) / σW(ATR)
// условие входа
volZMin ≤ atrZ ≤ volZMax  (0…2)

Классика quant-подходов к mean reversion: лучшие результаты даёт умеренно-повышенная волатильность. Экстремальный atrZ (> 2) часто означает новостной шок — σ переоценена.

Уровни SL/TP и риск

блок ④
// SL-дистанция в ATR-кратных · фиксированный R:R
SL = m·ATR    TP = t·ATR    t/m = 6/2 → 1:3
qty = (E · r%) / (SL · pv)
// безубыток: после +1R стоп → цена входа
P − P₀ ≥ be·SL ⇒ SL := P₀
// матожидание: E[R] = WR·3R − (1−WR)·1R
MR Score = clamp(50 + 10·z, 0, 100)

Индикатор чётко рисует по каждому сигналу две линии с ценовыми метками: SL и TP — и убирает их при выходе. Дефолт SL = 2×ATR, TP = 6×ATR даёт риск:доход 1:3, плюс режимы «Держать до SL/TP» (каждый выигрыш — полные 3R) и «Безубыток +1R» (стоп переносится на цену входа). Средние 3R/сделку математически невозможны (нужен 100% winrate) — а вот E[R] и PF поднимаются реально. В стратегии-версии формула даёт объём: E — капитал, pv — ценность пункта.

Корреляция Пирсона с BTC

блок ⑤
// скользящая корреляция монеты и биткоина
ρ = Σ(xᵢ−x̄)(yᵢ−ȳ) / (σₓ · σᵧ · n)
// приоритет направления при высокой |ρ|
|ρ| ≥ ρₜₕᵣ ⇒ BTC бычий → только LONG
// нормировка волатильности монеты
VR = ATR(монета) / ATR(BTC) ≤ 3.0

Для альткоинов корреляция с биткоином — главный системный фактор: при ρ ≥ 0.6 средняя реверсия монеты в направлении против битка почти не работает. Фильтр пропускает LONG только при бычьем BTC (цена выше EMA50) и SHORT — при медвежьем. Если альт в 3+ раза волатильнее BTC — входа нет.

06 · Практика

Установка и использование

Шаги установки

  1. 1

    В TradingView откройте график и нажмите «Pine Editor» на нижней панели (или сайт → «Продукты» → Pine Editor).

  2. 2

    Удалите шаблонный код и вставьте mr_quant_pro.pine (кнопка «Копировать» выше). По умолчанию активна версия индикатора.

  3. 3

    Нажмите «Добавить на график» — появятся полосы μ ± kσ, метки LONG/SHORT, а по каждому сигналу: зелёная прямая TP с ценой и красная прямая SL с ценой. Для бэктеста откройте вкладку «Стратегия» и добавьте её — внизу откроется Strategy Tester с чистой прибылью, профит-фактором и просадкой.

  4. 4

    Настройте параметры под таймфрейм (таблица ниже) и проверьте, что полужизнь T½ в панели метрик попадает в границы фильтра.

  5. 5

    Создайте алерт: ПКМ на графике → «Создать алерт» → условие MR Quant Pro. События LONG / SHORT / ВЫХОД встроены через динамические alert() — подробная настройка Telegram в разделе «Telegram» ↓.

07 · Уведомления

Сигналы в Telegram

Индикатор отправляет динамические сообщения через alert(): монета, таймфрейм, цена, z-score и уровни SL/TP. Чтобы они приходили в чат Telegram — один раз настройте webhook-алерты в TradingView.

Шаг 1 · Бот и chat_id

  1. 1

    В Telegram откройте @BotFather → команда /newbot → придумайте имя → получите токен вида 123456789:AAE-xyz...

  2. 2

    Напишите боту любое сообщение (или добавьте его в нужный чат/группу).

  3. 3

    Узнайте chat_id: напишите @userinfobot (личный чат) или откройте в браузере https://api.telegram.org/bot<ТОКЕН>/getUpdates — в ответе найдите "chat":{"id":123456789}.

💡 Для группы chat_id начинается с минуса (например -1001234567890) — используйте его целиком.

Шаг 2 · Webhook-алерт в TradingView

  1. 1

    На графике с индикатором: ПКМ → «Создать алерт» (или значок часов на панели).

  2. 2

    Условие: MR Quant Pro → выберите событие «MRQ LONG…» (или SHORT / ВЫХОД).

  3. 3

    Вкладка «Уведомления» → включите «Webhook URL» → вставьте шаблон ниже, заменив ТОКЕН и ID.

  4. 4

    Повторите для событий SHORT и ВЫХОД — в text укажите соответствующий сигнал.

// шаблон Webhook URL (LONG)
https://api.telegram.org/bot<ТОКЕН>/sendMessage?chat_id=<ID>&text=MRQ%20LONG:%20{{ticker}}%20{{interval}}%20@%20{{close}}%20z%20{{plot_0}}

08 · Лаборатория

Стратегия + цикл улучшения модели

Во вкладке «Стратегия» ↑ лежит та же модель, что и индикатор, но с исполнением сделок — TradingView сам посчитает всю статистику. Прогоняете на реальном графике → снимаете цифры по шаблону → присылаете мне → я дорабатываю модель (пороги, фильтры, режим выхода).

Шаг 1 · Запуск стратегии в TradingView

  1. !

    Не копируйте индикатор для теста — он не откроет Strategy Tester! Нужна вкладка «🧪 Стратегия» в разделе «Код» (или зелёная кнопка «Копировать стратегию» вверху страницы). Отличие простое: код стратегии начинается со слова strategy(, а индикатора — со слова indicator(.

  2. 2

    В TradingView откройте график монеты → Pine Editor (снизу) → вставьте код → «Добавить на график». Внизу появится Strategy Tester.

  3. 3

    Выберите таймфрейм (совет: начните с 1ч и 4ч — на них меньше шума) и период: иконка ⚙ у стратегии в панели объектов → «Свойства» → диапазон дат (вкладка «Свойства» в Strategy Tester).

  4. 4

    Убедитесь, что график в обычных свечах (не Heikin Ashi — искажает статистику). Для глубокой истории на 4ч/1д включите расширенную загрузку истории.

  5. 5

    Прогон закончен — снимите цифры из вкладки «Обзор» (Overview) и «Список сделок» (List of Trades).

💡 Стратегия уже содержит комиссию 0.05%, проскальзывание 1 пункт и стартовый капитал 100 000 — условия близки к реальным.

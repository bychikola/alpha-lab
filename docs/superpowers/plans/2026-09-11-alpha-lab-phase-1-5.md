- Python через `uv`; системный Python не трогать.
- pandas/numpy; без polars.
- Комментарии и docstring — на русском, идентификаторы английские.

## W1 — Целостность данных

**Файлы:** `src/alpha_lab/data/query.py`, `src/alpha_lab/data/quality.py`, `src/alpha_lab/cli.py`, `configs/experiments/mr_base.yaml`, `tests/`

- [x] **Разрывы.** Ряд режется на непрерывные участки, `generate` вызывается на каждом отдельно (состояние стратегии перезапускается на дыре по построению), плюс `_gap_mask` в CLI поверх `clean_mask` (`engine/` не тронут): обнуляется цель последнего бара перед дырой — `lookback=1`, `lookahead=0` (вперёд маска не нужна после сегментации; без lookback позиция прошла бы сквозь дыру через `held[i] = target[i-1]`). Решение зафиксировано в spec 8; `gap_masked_bars` — отдельный счётчик, предупреждение вердикта объясняет приостановку.
- [x] **`end` включительно.** Дата без времени (`"2025-12-31"`) означает конец дня (`ts < следующий день`); явный момент времени остаётся точной границей (`ts <= end`). Семантика описана в docstring `query.load_bars`.
- [x] **`include_delisted`.** Выбран вариант (a): ingest распознаёт оборванный хвост (`delisted`, `last_bar_ts`), при `true` пара остаётся в юниверсе и считается, при `false` исключается видимо (`excluded` + счётчики в CLI). `null` больше не превращается в `false`.
- [x] **`read_bars` glob** — `<symbol>-<freq>-*.parquet` вместо `*.parquet` (заодно в `query.load_bars`).

## W3 — Верификация

**Файлы:** `tests/`, `src/alpha_lab/causality.py` (новый), `cli.py`

- [x] **Критерий 4.** Сквозной тест: MR-стратегия на `ou_bars` (theta=0.02, seed=42, n=20000, объём откалиброван до ликвидности BTC-часа) → `run_backtest` → `validate` → `alive is True`; обратный контроль theta=0.002 → dead за статистику. Замер: theta=0.01 выживает на 8/10 seed'ов — «низкая theta» не синоним «нет края», честный контроль — theta ≤ 0.002.
- [x] **Критерий 7.** Тест воспроизводимости: при фиксированном журнале и исключённом `generated_at` два прогона дают одинаковый вердикт. Обновить формулировку критерия в spec 12.
- [x] **Harness в рабочий путь.** Перенести `tests/fixtures/causality.py` в `src/alpha_lab/causality.py` и вызывать из `_cmd_validate` **до** бэктеста: стратегия, не прошедшая проверку причинности, не получает вердикта. Это единственная работающая защита от look-ahead, и она не должна жить только в pytest.

## Критерии готовности фазы 1.5

1. Разрывы не торгуются (или прогон явно помечен недействительным) — с тестом на фикстуре с дырой.
2. Период `start..end` покрывает конечный день полностью.
3. Sharpe/Sortino/Calmar на 1d-эксперименте считаются с корректным годовым множителем.
4. Funding на 1d не теряется.
5. MR на OU проходит валидацию как `alive` (критерий 4).
6. Воспроизводимость подтверждена тестом (критерий 7).
7. CLI отказывается выдавать вердикт стратегии, не прошедшей проверку причинности.
8. PBO вычисляется для многоконфигурационного прогона.
9. Полный набор тестов зелёный под `-W error`; вердикт по BTC остаётся `МЕРТВА`.
10. Spec приведён в соответствие: 5, 8, 12.
